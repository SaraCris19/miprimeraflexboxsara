Niveles de especificidad

Cuando dos reglas CSS le dan estilos distintos al mismo elemento, el navegador no elige la que está más abajo: elige la más específica. Cada selector recibe una puntuación A,B,C: A cuenta los #id, B las .clases, [atributos] y :pseudoclases, y C las etiquetas y ::pseudoelementos. Gana el valor más alto.

01

Selector de etiqueta

div { }

Una etiqueta suma 1 en la columna C. Especificidad: 0,0,1.

02

Dos etiquetas

div div { }

Cada etiqueta suma 1 en C. Especificidad: 0,0,2.

03

Una clase

.container { }

Las clases suman en la columna B. Especificidad: 0,1,0.

04

Dos clases

.container .item { }

Dos clases, dos puntos en B. Especificidad: 0,2,0.

05

Selector de atributo

input[type="text"] { }

Un [atributo] cuenta como una clase (B) y la etiqueta suma en C: 0,1,1.

06

Un ID

#pagina div { }

Un ID suma en la columna A, la más fuerte. Especificidad: 1,0,1.

07

ID + pseudoclase

#pagina div:hover { }

:hover es una pseudoclase y suma en B: 1,1,1.

08

Selector largo

#pagina div:hover a { }

Un ID, una pseudoclase y dos etiquetas: 1,1,2.

09

Con combinador

#pagina .sel:hover > a { }

El combinador > no suma nada. Resultado: 1,2,1.

10

Pseudoelemento

p::first-line { }

Los ::pseudoelementos cuentan como etiquetas (C): 0,0,2.

11

La fórmula A,B,C

A = #ids
B = .clases [atributos] :pseudoclases
C = etiquetas ::pseudoelementos

Cuenta cuántos hay de cada tipo. Las DevTools del navegador también te muestran el valor.

12

¿Quién gana?

#element { background: indigo; }
.container { background: red; }

Si el div tiene los dos, gana #element (1,0,0 contra 0,1,0): el fondo es índigo.

13

Se compara por columnas

#menu       → 1,0,0
.a .b .c .d → 0,4,0

Primero se compara A; si empatan, B; luego C. Un ID vence a cualquier cantidad de clases.

14

El orden no manda

#titulo { color: green; }
h1 { color: red; }

Aunque h1 esté más abajo, el título queda verde. El orden solo decide cuando hay empate.

15

:is()

.container :is(.item, #unique) { }

Toma la especificidad de su argumento más específico (#unique): 1,1,0.

16

:not()

.container :not(.item) { }

Usa la especificidad de lo que tiene dentro: 0,2,0.

17

:has()

.container:has(.item) { }

También suma su argumento más específico: 0,2,0.

18

:where()

.container :where(.item) { }

:where() siempre vale 0, tenga lo que tenga dentro: 0,1,0.
